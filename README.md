# LexiCore 分级背单词

一个面向中小学生的分级背单词 Web App：首页按 CEFR 难度（Pre-A1 → B2）组织，并提供「分级」页按**人教版教材**划分小学 / 初一 / 初二 / 初三 / 高一 / 高二 / 高三 七个阶段。支持单词发音（本地 Piper TTS）、释义 / 例句查看、掌握进度标记与本地持久化。

> 本应用仅用于个人学习用途。
